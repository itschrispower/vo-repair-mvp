VO REPAIR LAUNCH FIX — macOS Tkinter Crash Resolution
======================================================

PROBLEM:
  Tkinter crashes on macOS when launching via double-click of local_run.command
  Root cause: Apple CommandLineTools Python 3.9.6 has broken Tcl/Tk runtime
  Symptom: Tcl_Panic → TkpInit crash in /usr/bin/python3

SOLUTION:
  local_run.command now explicitly detects and uses:
  1. /opt/homebrew/bin/python3 (Homebrew on Apple Silicon) — PREFERRED
  2. /usr/local/bin/python3 (Homebrew on Intel Mac) — FALLBACK
  3. /usr/bin/python3 (System Python) — LAST RESORT

FILES CHANGED:
  • local_run.command — Complete rewrite with Python detection & error handling

NO CHANGES REQUIRED TO:
  • run_app.py — Works as-is
  • gui_app.py — Works as-is
  • Any other files

  4. Dependencies install
  5. GUI window opens
